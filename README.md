# Mural Mobile

Web app instalável para consultar uma biblioteca pessoal de salvos do X e Reddit no iPhone.

## Privacidade

O site não inclui biblioteca, bookmarks ou dados pessoais. O arquivo JSON escolhido pelo usuário é processado no navegador e armazenado localmente pelo IndexedDB. Imagens dos posts são carregadas diretamente dos domínios do X e Reddit.

## Uso

Abra o site no Safari, importe um backup exportado pelo Mural no Mac e use **Compartilhar → Adicionar à Tela de Início**.
